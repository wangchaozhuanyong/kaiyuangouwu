# 购物恢复、关联及商品编辑修复

本次发布使结算失败后的重试保留已确认的购物状态，并修复商品关联、编辑权限、数字交付、成本清空和订单声音的恢复行为。所有店铺使用相同实现和后台配置。

## 发布内容

1. 购物恢复：保存已确认事实，区分结算、立即购买和付款意图；整体 20 秒时限、共享取消与迟到响应保护；恢复不重放已确认写入，支付方式读取不阻塞导航。
2. 商品关联：按完整 ID 分批核验，区分有效、失效和未知；保留顺序及草稿，部分成功只重试剩余项；实时资格先于限额和分页，搜索索引成功后通知相关缓存失效。
3. 商品扩展：稳定权限与扩展边界，修复 React #301；保存成功后的只读重试保留其他草稿。
4. 数字交付：区分本店未启用与实际库存；允许未保存状态的只读预览，绑定文件和迁移前验证，提供局部撤回而保留其他输入。
5. 可选成本：省略保持原值、null 清空、0 有效；保留历史审计，缺成本区间不计算利润。注册前向迁移 `AllowUnsetCatalogCost1791676800000`，仅改变成本历史列的可空性。
6. 订单声音：开关移至搜索与主题之间，使用事件所属店铺的中英文名称；跨标签页单连接、静音同步、接管及订单去重；语音等待有界并保留 mp3 回退与限流边界。
7. 商品编辑：合并为两组编辑分区，保留旧入口、挂载草稿、保存及错误定位，支持宽窄屏。
