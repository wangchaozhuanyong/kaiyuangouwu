# 分类持续同步使用说明

入口：平台管理中心 → 商品管理 → 平台商品分配 → **分类持续同步**。

本次发布只上线功能，所有规则默认关闭。下列创建与启用操作会写入真实店铺，需在确定来源分类及目标店铺后执行。

1. 选择来源经营店铺 A 和来源分类。默认包含全部子分类及全部分页；平台管理中心不能作为货源。
2. 勾选目标经营店铺 B，可同时选择多个目标。点击“保存为关闭的规则”，此时尚未上架或同步商品。
3. 对目标点击“生成同步预览”，核对商品及分类数量、目标币种和标价、交付待配置项及接管差异。
4. 存在已有独立经营配置时，逐项核对后勾选接管确认；存在阻塞项时先修复来源条件。跨币种复用目标店已有的固定人民币／马币换算。
5. 点击“启用此分类持续同步”。“等待同步”仅代表任务已受理；在“各目标同步状态”刷新核对完成状态。

已有商品分批同步，后续新增商品、规格、子分类及经营配置继续跟随来源。目标店的受管价格、库存和交付设置由来源管理。销售使用原始货源库存和卡池，不复制一份库存数量。

| 页面状态／操作 | 含义及处理 |
| --- | --- |
| 尚未建立规则 | 功能可用，但未执行任何生产分类同步 |
| 等待同步／正在同步 | 等待或执行后台任务，不能据此认定整类已全部上架 |
| 已完成 | 当前扫描结束；仍需结合目标商城可见商品及逐项结果核对 |
| 部分待处理 | 点击“查看逐项原因”，补齐固定汇率、配送或交付条件后“重新对账／续做失败项” |
| 暂停同步销售 | 停止新的受管购买，已接受订单继续按原始来源快照履约；暂停不等于解除接管 |

混合订单会按货源分别选择配送方式，再显示一个订单的运费合计。客户、订单、收款账户、优惠券和税务仍归目标店铺管理，因此优惠后的实付金额可能与来源店不同。

正常队列下增量同步的验收目标为 60 秒，漏事件由五分钟补偿调度处理。万件初次导入耗时单独记录，不能套用增量目标；本地测量也不代表生产容量承诺。

异常时先暂停并保留订单及来源快照，按 [迁移与恢复说明](MIGRATION.md) 向前修复。不要删除映射表、卡池、库存流水或历史订单。
