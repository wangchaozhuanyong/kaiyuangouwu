# Safety rules

Block before any provider call when the request involves:

- sexual content involving minors or age-ambiguous people;
- non-consensual intimate imagery;
- deceptive impersonation or face swaps of public figures;
- instructions that meaningfully facilitate violent, criminal, or fraudulent harm;
- hateful degradation or targeted harassment;
- requests to remove provenance marks or misrepresent AI media as authentic evidence.

Ordinary portraits of adults are allowed. Reference-image users must confirm they own the image or have permission to use it. Do not infer sensitive traits. Preserve provider provenance metadata and watermarks.

When a request is ambiguous, keep the safe portion and explain the removed element. Never silently rewrite a prohibited request into a look-alike result.
