# 推广入口页设计规范

## 页面任务

这个页面是面向推广平台、搜索引擎和首次访客的业务介绍层，不是商品目录或交易页。

- 让访客在 10 秒内理解站点提供什么。
- 只介绍业务类型、服务路径和主站职责。
- 不输出实时商品、价格、库存、商品 ID 或完整商品链接。
- 推广页可收录但不跟踪：`index,nofollow`。
- 主域名始终直接进入主站；推广流量可单独进入 `/promo` 了解业务后再跳转。
- 推广页的“进入主站”仍使用短时签名票据，防止表单被篡改，但该票据不是主站访问前置条件。

## 内容架构

1. **首屏定位**：一句价值主张、业务范围、单一主行动。
2. **服务能力**：AI 接入、软件订阅、数字交付、订单与售后。
3. **职责分层**：推广页负责介绍，主站负责完整信息、交易和服务。
4. **进入流程**：了解范围→进入主站→确认详情与下单。
5. **最终入口**：重复单一主行动，并保留隐私、条款和客服入口。

## 视觉系统

- **基底**：矿物黑 `#070B0D`，不使用纯黑。
- **表面**：石墨绿黑 `#0C1314` / `#101A1A`，使用少量玻璃折射边缘。
- **唯一强调色**：离子薄荷 `#91E6C4`，用于入口、状态、线性节点。
- **文字**：雾白 `#EDF4F0`，次级文字使用同一冷绿灰色族。
- **字体**：`Avenir Next` / `SF Pro Display` / `PingFang SC`，避免通用 Inter 模板感。
- **布局**：非对称 12 列网格；首屏文字与信号核偏置；能力卡使用 7/5、5/7 交错占位。

## 动效原则

- 保留 WebGL 信号核，重新着色为矿物黑与薄荷绿。
- 指针移动只影响光场、边缘折射和微小视差，不做追随光标的夸张效果。
- 区块进场采用透明度、位移和裁切掩膜，延迟幅度不超过 240ms。
- 所有动效支持 `prefers-reduced-motion`；移动端限制到 36fps。
- 页面不依赖第三方动画库或外部字体，避免增加加载与 CSP 风险。

## 安全与收录边界

- `/promo` 允许收录，页内不输出可跟踪到商品的普通链接。
- 主站和 Shop API 直接开放浏览；账户、订单、付款与管理操作继续由各自的身份认证和权限校验保护。
- `robots.txt` 只是搜索引擎协议，不视为安全边界。
- 如需要把“只有真实用户能提交入口”变成强约束，后续需在 `/promo/enter` 接入 Cloudflare Turnstile 并完成服务端校验。
