## 实现范围

- 新增 `packages/news-blog-plugin`：六张按 Channel 隔离的业务表、CAS 版本保护、发布快照、审核人及发布/撤稿历史、来源与运行记录、采集/文本/图片队列、调度器、公开与后台 API。

- 后台增加四个工作区、文章编辑与来源并排预览、候选标题、段落/封面重做、图片替换、版本冲突保护、人工审核发布、撤稿和版本查看。新闻没有自动发布路径；热门 Skill 采用下述独立自动推荐流程。
- 商城增加 `/zh/blog` 与 `/zh/blog/:slug`：精选、分类、搜索、分页、三列/手机单列、阅读时长、目录、来源、关联服务及相关文章。保留 `/guides`。
