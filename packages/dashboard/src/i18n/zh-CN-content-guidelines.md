# Vendure 管理后台中文内容规范

## 目标用户

界面主要面向中国电商运营、客服、仓库人员和系统管理员。文案应先说明业务含义，再保留必要的技术名词，不要求用户理解 Vendure 的英文领域术语。

## 编写原则

1. 中文是业务含义的权威版本，英文根据中文含义编写，不逐字反向翻译。
2. 按钮使用“动词 + 对象”，例如“创建商品”“分配到渠道”“取消订单”。
3. 状态使用明确的完成时态，例如“待处理”“处理中”“已完成”“已取消”。
4. 错误信息应包含失败事项；已知时补充原因和下一步操作。
5. 同一个业务概念在导航、标题、表格、表单和帮助中必须使用同一名称。
6. SKU、API、URL、ID、GraphQL、Vendure 等通用技术词可以保留英文，但首次出现时应补充中文解释。
7. “界面语言”“内容语言”和“地区格式”必须分别表述，不能统称为“语言”。

## 核心术语

| 英文术语        | 中文名称     | 使用说明                                                                 |
| --------------- | ------------ | ------------------------------------------------------------------------ |
| Product         | 商品         | 商品的基础信息，不包含具体颜色、尺寸等销售规格                           |
| Product Variant | 商品 SKU     | 可独立定价、管理库存和销售的具体规格                                     |
| Option Group    | 规格组       | 例如颜色、尺寸                                                           |
| Facet           | 筛选属性     | 用于后台筛选、店铺筛选和商品归类                                         |
| Collection      | 商品分类     | 支持一级、二级及多级分类，可手动或按规则归类商品，用于前台导航或专题展示 |
| Asset           | 素材         | 图片、文档等可复用文件                                                   |
| Channel         | 销售渠道     | 不同店铺、地区、品牌或业务入口                                           |
| Seller          | 商家         | 多商家模式中的销售主体                                                   |
| Stock Location  | 仓库与库存点 | 实际存放和扣减库存的位置                                                 |
| Promotion       | 促销活动     | 折扣、满减、优惠券等营销规则                                             |
| Job Queue       | 后台任务     | 导入、索引、邮件等异步任务                                               |
| Settings Store  | 系统配置     | 系统或插件保存的配置项                                                   |
| Slug            | URL 标识     | 用于组成页面访问地址的可读标识                                           |

## 操作帮助规范

页面级帮助统一放在页面标题右侧，点击问号后从右侧打开。内容按以下顺序编写：

1. 这个页面用于什么。
2. 建议的操作顺序。
3. 会影响哪些数据或前台行为。
4. 需要注意的权限、依赖和不可逆风险。

字段级问号只用于含义不直观、配置后果较大或需要格式约束的字段。删除、取消、密钥重置等高风险操作必须在操作区和确认框中直接说明后果，不能只依赖问号帮助。
