# 商品内容与上架规范

## 1. 适用范围

本规范用于当前两个店铺 Channel：

- `cn-mainland`：默认中文，币种 `CNY`。
- `my-malaysia`：默认英文，币种 `MYR`。

客户端只支持中文和英文。后台以 `zh_Hans` 作为源内容，保存时自动生成 `en`；只在品牌名、专业术语或营销文案需要精确控制时才人工校对英文。不新增马来语内容。

## 2. 当前可直接录入的字段

| 内容          | Vendure 数据                      | 录入要求                                                           |
| ------------- | --------------------------------- | ------------------------------------------------------------------ |
| 商品名称      | Product translation `name`        | 录入中文源文，保存后自动生成英文；不在同一名称中混排两种语言       |
| 商品说明      | Product translation `description` | 首句说明商品是什么，再写用途、核心配置和交付方式                   |
| 商品图片      | Product / Variant Asset           | 首图用于列表、搜索和详情页，规格图可按 Variant 维护                |
| 商品规格      | ProductVariant translation `name` | 写用户可选的差异，例如容量、颜色或交付版本                         |
| SKU           | ProductVariant `sku`              | 全局唯一、稳定，不使用商品中英文名称作为 SKU                       |
| 价格          | ProductVariantPrice               | `cn-mainland` 和 `my-malaysia` 分别维护，小数货币按最小单位存储    |
| 库存          | StockLevel                        | 实物商品启用库存跟踪，数字商品不用虚构库存数                       |
| 实物/数字交付 | ProductVariant `fulfillmentType`  | 只使用 `physical` 或 `digital`，该值会决定结账时是否需要地址和配送 |
| 分类          | Collection                        | 用于主导航、分类页和人工推荐，不用 Facet 代替分类                  |
| 筛选属性      | Facet / FacetValue                | 只放需要在列表筛选的结构化属性，例如类型、颜色、材质               |

## 3. 文案规范

### 商品名称

- 中文建议使用“品牌/系列 + 型号 + 商品类型 + 核心区分”。
- 自动生成的英文默认使用 sentence case；品牌官方拼写不准确时再人工校对，不全部大写。
- 不在名称中堆叠“爆款”“顶级”“全网最低”等无法验证的促销词。
- 名称应在手机端两行内可识别，重要区分信息放在前半段。

### 商品说明

- 第一段回答“这是什么、适合谁、解决什么问题”。
- 数字商品必须说明交付介质、交付时间、使用条件和有效期。
- 实物商品必须说明包装内容、主要规格和配送限制。
- 中英文要传达同一事实，不要直译导致交付或售后含义不一致。

## 4. 图片规范

| 用途            | 建议尺寸    | 要求                                                                         |
| --------------- | ----------- | ---------------------------------------------------------------------------- |
| 商品首图/规格图 | `1600×1600` | 关键内容放在中央 80%；手机按 1:1 显示，桌面放入 4:3 容器并完整显示，不强裁切 |
| 首页 Hero       | `1600×900`  | 主体靠右，左侧 46% 保持低细节；按钮、价格和时效文案使用页面文字层            |
| 分类/内容横幅   | `1600×900`  | 同一系列保持一致光线、背景和色温，每张只保留一个视觉焦点                     |
| 社交分享图      | `1200×630`  | 中央 84% 为安全区，只放品牌、短价值句和默认域名                              |
| 推荐分享海报    | `1080×1920` | 左右至少 64px 安全区，二维码四周不得有纹理、文字或高对比装饰                 |
| 站点图标        | `512×512`   | 只使用方形图标，不把横版 Logo 压缩进正方形                                   |

- 优先使用 WebP 或优化后的 JPEG；上传前删除不需要的元数据。
- 品牌视觉只使用 `#635BFF`、`#8B5CF6`、`#22D3EE`、`#FFFFFF`、`#070B14` 及其透明度变化；状态色除外。
- 图片不应带第三方水印、虚假认证标识或无法证明的销量数据。
- 首图必须真实展示商品、数字内容的实际界面或明确的服务概念，不使用纯氛围占位图。
- 不把规格表、长段卖点、价格、促销时限或 CTA 烘焙进图片；这些内容应由后台字段和页面组件呈现。

## 5. 价格、税费与库存验收

- Vendure 中录入的价格为最小货币单位，例如 `429900` 表示 `CNY 4,299.00`。
- 客户端显示 `priceWithTax`，不应在浏览器中自行加税或减税。
- 当前两个商店都是 `pricesIncludeTax = false`，因此后台基础价与前台含税价可能不同。
- 每个商品上架前必须在 `cn-mainland` 和 `my-malaysia` 分别回读前台价格，不用汇率自动推算另一个市场的售价。
- 实物 Variant 的可售库存为 `stockOnHand - stockAllocated`，不直接把手工表格数字当成前台库存。

### 当前演示环境的已知配置风险

- `my-malaysia` 暂时与中国大陆店共用同一 Tax Zone，不能作为马来西亚正式税率。
- 当前只有测试配送方式，包含固定演示运费。
- 当前只有 `dummy-payment-handler` 测试支付，不得用于生产收款。

## 6. 当前不应凭空录入的字段

下列内容尚无已确认的数据字段，不应塞入商品描述后再由前端解析：

- 品牌及品牌图标。
- 可排序的技术参数表。
- 保修期、保修方式和适用地区。
- 包装清单、重量和尺寸。
- 单品退换货限制。

如果需要在商品详情页结构化展示这些内容，应先确认数据模型，再新增 Product 或 ProductVariant custom fields 及对应迁移。

## 7. 本地临时商品目录

项目提供 4 个可重复执行的临时实物商品，用于检查首页、分类页、商品详情和移动端密度。所有 SKU 均以 `DEMO-` 开头，文案会明确标记为临时演示数据。

运行前先备份本地 SQLite 数据库，再向当前本地 Vendure API 写入：

```bash
VENDURE_API_ORIGIN=https://vendure.localhost:1355 \
SUPERADMIN_USERNAME=<local-admin> \
SUPERADMIN_PASSWORD=<local-password> \
NODE_TLS_REJECT_UNAUTHORIZED=0 \
bun run --cwd packages/dev-server seed:storefront-demo
```

脚本只接受本地 API 地址，并按 SKU 与资源标签更新，重复执行不应创建重复商品。这些数据只用于本地预览，不得导入生产数据库。

商品写入后，需要在另一个终端启动与 API 使用相同数据库的 Vendure Worker，才会更新搜索索引。当前 SQLite 预览命令为：

```bash
DB=sqlite bun run --cwd packages/dev-server dev:worker
```

如果 API 改用其他数据库，Worker 必须同步使用相同的 `DB` 和连接参数，不得同时连入另一个本地库。

## 8. 单品上架验收清单

- [ ] 中文名称、描述和规格已录入并保存。
- [ ] 自动生成的英文已通过上线完整性检查，必要时完成人工校对。
- [ ] SKU 唯一，实物/数字交付类型正确。
- [ ] 首图与规格图在手机端和桌面端没有关键裁切。
- [ ] 图片遵守对应比例和安全区，加载前后卡片高度保持稳定。
- [ ] Collection 与用于筛选的 Facet 已分别维护。
- [ ] `CNY` 和 `MYR` 价格均已独立录入并前台回读。
- [ ] 前台含税价与已批准的市场税率一致。
- [ ] 实物商品库存、配送范围和运费已验收。
- [ ] 数字商品的交付时间、使用条件和有效期已说明。
- [ ] 不再含有“临时演示”“待审核”或测试承诺文案。
