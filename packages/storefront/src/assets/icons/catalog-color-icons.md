# Shared catalog navigation artwork

These two decorative UI images are shared by every storefront. They represent fixed navigation concepts; merchant category photographs continue to come from Admin content.

- `catalog-directory-color.webp`: colorful category grid.
- `catalog-products-color.webp`: shopping bag with product parcels.

Created with the built-in imagegen tool on 2026-09-26. Transparent PNG originals were optimized to 128 × 128 WebP using the repository's existing Sharp dependency, with alpha retained and no artwork recoloring. No trademarks, text or logos are included.

## Generation prompts

### Category directory

Use case: stylized-concept. Asset type: one production ecommerce navigation icon image for 'All categories'. Create a polished colorful 3D miniature icon: four solid rounded square blocks arranged in a precise 2 by 2 grid, in soft teal, cobalt blue, coral orange and warm yellow. Refined satin ceramic texture, slight beveled depth, nearly frontal view so the four blocks read clearly at 28px. One compact centered silhouette filling about 84% of the square canvas with balanced equal margins. Gentle studio light, restrained small ambient shadow. Genuine transparent background with alpha. Single icon only, no surrounding card, no white square background, no text, no letters, no logos, no watermark, no outlines. Optimized for cream and dark themed storefronts, clean edges, visually balanced with a matching miniature shopping bag and parcel icon.

### All products

Use case: stylized-concept. Asset type: one production ecommerce navigation icon image for 'All products'. Create a polished colorful 3D miniature icon: a soft teal shopping bag with a simple blue rounded handle behind one small coral orange parcel and one warm yellow rectangular product box, composed as one compact recognizable shopping assortment. Refined satin ceramic texture, slight beveled depth, nearly frontal view. Bold simple shapes that remain legible at 28px, no tiny decorations. One centered silhouette filling about 84% of the square canvas with balanced equal margins. Gentle studio light, restrained small ambient shadow. Genuine transparent background with alpha. Single icon only, no surrounding card, no white square background, no text, no letters, no logos, no watermark, no outlines. Match the visual language of a four-color teal/blue/coral/yellow 2 by 2 category block icon, suitable for cream and dark themed storefronts.
