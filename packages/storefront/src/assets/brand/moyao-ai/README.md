# MOYAO AI runtime brand assets

These files are optimized derivatives of the approved `MOYAO_AI_Logo_Brand_Pack.zip`.

- `app-icon.webp`: square gradient icon for compact UI.
- `logo-on-light.webp`: horizontal wordmark for light surfaces.
- `logo-on-dark.webp`: horizontal wordmark for dark surfaces and publishing.
- `icon-monochrome.svg`: source-pack monochrome mark for one-color use only.

Brand colors are `#635BFF`, `#8B5CF6`, `#22D3EE`, `#FFFFFF`, and `#070B14`. Keep the source proportions, use `object-fit: contain`, and do not add shadows or recolor the official gradient artwork.
