# 商城加载、刷新与交互统一标准

版本：2026-10-25「目标即时响应、区域加载」。适用共用商城客户端、桌面与手机、中英文及客户端插件。本标准完整替代此前叠加的加载规则；后台遵守自身实现。它不授予发布、生产数据修改或支付操作权限。

## 体验目标

用户通常直接看到品牌、导航、内容和首屏图片。已经出现的有效内容持续可见；导航往返不重播品牌开场；下方图片在接近视口时提前加载。骨架、品牌等待与错误反馈只对应真实缺失或故障，不成为每次访问的必经流程。

继续使用现有 Query、Router、SafeImage、公共首屏快照和 Admin 配置。保留店铺内容、图片、布局、主题及交易权限规则；不新建第二套请求、缓存、轮询或品牌持久存储。不能通过隐藏整页、延长遮罩、等全部图片或删除反馈制造“稳定”。

## 场景设计

| 场景                      | 可见内容与操作                                                       | 等待和恢复                                                                                              |
| ------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 首次进入，有有效公开 HTML | 立即显示服务端正文与图片，接管前后同一响应式结构；公开入口有真实链接 | 启动慢于200ms显示紧凑状态，真实路由提交后交给React，不等优惠等局部读取                                  |
| 首次进入，尚无页面        | 唯一品牌等待；品牌来自已校验当前店铺，未知时中性呈现                 | 内容可用立即结束，无最低播放时间；启动失败或超时有重载入口                                              |
| 店铺配置未确认            | 不展示另一店铺的品牌、商品                                           | 由现有Boundary显示首载等待或错误；配置确认后先放开壳层                                                  |
| 浏览器刷新                | 旧文档保留至浏览器替换，新文档使用自身HTML和缓存                     | beforeunload不隐藏或inert旧页；取消刷新后原页仍可操作                                                   |
| 已访问导航                | 同作用域缓存直接显示，保留壳层，过期数据后台更新                     | 不清空页面、不重新淡入已载图片；短导航不强制等待反馈                                                    |
| 尚未准备好的导航          | 立即呈现目标导航与目标正文占位，页头和底栏持续可用                   | 叶路由pendingMs与pendingMinMs均为0；目标骨架独占等待反馈；无区域占位且超过200ms才显示中央非阻挡状态；身份和回调属于同一目标 |
| 快速连续点A/B/C           | 最新有效意图优先，每个目标独立计算等待期限，旧响应留在自己的查询范围 | 返回或新导航取消旧意图；迟到响应不能覆盖当前页，重试针对当前目标                                        |
| 后退、前进、详情返回列表  | 恢复URL、条件、分页和已有滚动记录                                    | 不额外push“返回”节点；未知历史回安全入口；不把列表摘要当完整详情                                        |
| 首屏图片                  | 正确候选和固定比例，浏览器已载像素直接呈现                           | 显示不等JS decode回调；ready及onImageReady仍要求当前候选实际成功解码                                    |
| 屏外图片                  | 懒加载，接近视口时提前请求                                           | 保留准确几何，不等进入图片框才开始，也不抢载全站图片                                                    |
| 图片替换、轮播            | 新图可呈现前保留可用旧图，保留object-fit/position                    | 错误局部降级，不改变图片框高度；旧URL缓存不代表新节点就绪                                               |
| 搜索、筛选                | 输入及时响应，URL表示确认条件；同条件缓存可复用                      | 无目标数据只更新结果区；不把旧条件结果当新结果；IME组合不提交半成品                                     |
| 分页、加载更多            | 保留已有条目，仅尾部反馈                                             | 合并重复读取，失败仅在分页处重试；成功零条明确表示结束或空结果                                          |
| 优惠、推荐、评论          | 有什么先显示什么，缺失模块在自己位置等待                             | 局部失败不隐藏整页、不延长文档启动提示                                                                  |
| 后台刷新 | 保留内容、滚动、筛选和草稿 | 正常更新静默；失败由共用轻提示说明并允许重试/关闭 |
| 弹窗、抽屉 | 先有可关闭的真实外壳、正确焦点与滚动锁 | 内部自行加载；离开所属页面释放遮罩和锁 |
| 按钮、表单、购物车操作 | 操作处及时反馈busy，仅限制重复/冲突操作 | 区分成功、失败与写入成功但展示更新失败，不自动再次写入 |
| 断网、资源故障 | 可用内容保留；离线、错误、真正空结果明确区分 | 当前区域可重试；入口模块无法启动才提供整页重载 |
| 店铺未开放、访问拒绝 | 明确终态及适用的重新检查入口 | 结束启动监控，不在十秒后叠加“仍在启动”的假错误 |

首页优惠区在首帧已有可领取优惠时显示；确认无券、数据未知或个人资格未确认时，不生成模块与间距。本次首页不因迟到数据插入专区，后续自然进入首页可使用同范围、同身份且仍新鲜的已准备结果。公开结果由现有后台预热提供，访客读取不等待优惠源；服务端 HTML 与客户端首次渲染使用同一结果。后台读取中或失败保留已有有效券，领取、过期等真实业务变化可以更新布局；后台未启用的优惠模块不渲染。个人结果不进入公共快照，账号、店铺、币种和语言切换隔离。验收应逐帧检查下方商品位置，不能只比较最终滚动数值。

## 品牌与动效

- 2026-10-28 轻柔呈现：已有公开HTML与缓存内容直接显示，不在接管、后台刷新或往返时重播入场。真实首次等待结束后，仅对已标记且当前可见的正文分组使用有限的透明度与位移过渡；最多4组，每组240ms，间隔60ms，手机4px/电脑6px。主图、页头、底部导航与滚动容器保持稳定；用户开始滚动或操作、离开目标或开启减少动态效果时立即结束过渡。动效不决定数据就绪、不拦截操作、不增加最低等待。
- 文档启动提示退出使用120ms透明度过渡，交互与busy在实际接管时立即释放。当前入口不加载旧同步主题恢复脚本；已确认的服务端主题拥有首帧，未知店铺保持中性。兼容旧文档的历史主题脚本和缓存不因此清除。
- Logo、店名、副标题来自当前已确认配置；保留原色和比例，不能借用另一店铺缓存。
- 空页面完整品牌等待沿用文字下细条；有内容时紧凑反馈。不显示虚假百分比、不为动画延迟进入。
- 导航选中项和目标占位立即响应；目标骨架已呈现时不叠加中央品牌反馈，并保留可访问的加载状态。无区域占位时中央动态反馈延迟200ms，完成立即撤销。加载较慢与失败的反馈在同一区域交接。空HTML可立即呈现品牌，无须等脚本；React已可呈现内容则无需强制品牌开场。
- 缓存图片不从透明重新淡入；菜单、弹窗、轮播保留必要局部动效。
- 图片覆盖式/广告框架轮播的文案从首帧采用已发布主题或明确文字颜色，接管后不再按像素采样二次变色。明亮主题用深色，其他主题用浅色；商家明确设定优先。图文分离的原有局部适配继续保留。
- 减少动态效果时遵守prefers-reduced-motion。失败停止动画与busy；提示不抢焦点、不锁导航。

## 文档接管与读取分工

1. HTML启动节点在React root外，仅负责入口脚本未接管阶段。启动脚本非阻塞，不设置root的hidden、visibility或inert。
2. 空root显示完整品牌；已有SSR只允许紧凑、非遮挡反馈。服务端data-page-readiness=ready不能证明客户端已接管。
3. storefront:app-owned表示React已承接页面及等待/错误UI。公开SSR以usePageRouteCommit的真实提交为前提；纯客户端Boundary与“店铺未开放”终态在实际提交时交接。该信号不承诺全部局部模块完成。
4. storefront:page-ready与NAV_READY只表达当前目标必要读取就绪，供既有延后UI使用。优惠、推荐等optional token不延后就绪；实际必要读取失败不得报告ready。局部token不能扣住文档启动层。
5. Boundary整屏首载仅用于未确认店铺且没有可用内容；站内导航由叶路由立即提交目标占位，根App和共享导航持续挂载。普通公开数据预读不阻塞路由提交；目标页内缺失的数据由所属Query和区域接管。React可保留不可见的旧子树以支持返回，但旧控件不得可见、可聚焦或冒充目标内容。
6. 入口十秒无法启动时停止动画并提供重载，迟到真实提交可恢复。数据十秒后提示加载较慢并允许等待、重试或返回；这不是请求失败，不触发NAV_ERROR。真正的失败、断网和既有传输超时进入错误恢复；不添加无上限等待。
7. 图片不参与整页readiness。SafeImage独立处理候选、超时、失败及恢复。
8. beforeunload不改变旧文档；bfcache返回不重复品牌或错误锁。

9. 提前读取、正式读取、GraphQL兼容回退与Query自动重试共用一次只读操作的20秒总预算；Query是自动重试的唯一负责人。导航取消与真正超时分开，均不自动重试；写入沿用原有防重复与结果不明恢复机制。
10. 发布切换保留上一版本哈希资源的原URL至少7天，后续发布只传递未过期资源，不延长继承资源的期限。HTML、SSR及原生资源仍来自同一候选；不能用自动刷新正在结算或填写资料的页面代替兼容。
11. 后台PAGE、相对URL、同源绝对URL共用现有内部导航；真实href、外链、下载、电话、邮件和隔离工具保留原语义。传递异步操作回调时必须传回Promise，调用方才能等待完成、显示失败并防止提前切换语言或关闭弹层。
12. sessionStorage只保存最多32项公开查询、每项最多3页、总计256KiB的副本，保留Query内存中的完整列表。后台写入合并后在空闲时执行，不因观察者挂载重复序列化；配置、PREVIEW与私有数据仍不得持久化。
9. 客户端未接管时，公开原生链接可以跳转；点击尚未连接的JS按钮立即显示启动提示，不缓存、不重放该操作。实际接管后移除临时捕获，不修改React根节点属性。
10. 可缓存的文档启动脚本在规则更新时同步推进入口URL版本，确保已有浏览器和CDN缓存不会继续执行旧规则；不通过清空用户缓存或清除会话解决版本交接。
11. 整页离开时把滚动恢复交还浏览器，已接管页面的 pageshow 再交回 Router；站内导航沿用现有 Router 恢复键和记录，不建立第二套滚动存储。不能先绘制页面顶部，再等 React 的路由提交回到原位置。验收必须逐帧覆盖顶部与滚动后刷新，并检查整页位置、样式和图片；最终 scrollY 正确不代表中间没有闪跳。

当前目标导航与各区域读取独立计算等待期限和重试归属；可选区域不能触发整页等待。已离开的页面不能屏蔽目标提示，也不能消费目标等待期限；局部重试只重启对应读取，导航重试只处理当前目标。离开前记录来源滚动，目标占位提交时交接，后退与前进恢复原有位置；等待期间打开的登录窗口归属已经呈现的目标，迟到的模块完成不能关闭窗口或丢弃草稿。

## 图片画面的统一交接

- 首屏候选由共享选择器按已发布内容及实际断点确定；HTML 与导航预载使用同一规则。只提升当前可见的横幅或详情图，不抢载屏外图片、其他分类商品或手机端隐藏的装饰图。
- 公开图片预览由现有媒体清单授权，复用图片服务器的变换队列和衍生缓存；每张不超过1KB、每次最多8张/8KB，转换最多并行2个、总等待预算250ms。失败或预算耗尽不阻塞页面。
- 预览属于当前店铺、币种、语言、host 和内容版本的公开数据。公开正文与登录入口复用既有页面/启动缓存；SSI只读已准备的内容，不在文档请求内读取原图或转换图片。全冷缓存尚未准备时保留真实局部等待。
- 响应式预览逐分支绑定原图；某断点缺少预览时保留中性占位，不能退回另一断点的图片。原生 `<picture>` 候选与缓存隔离继续生效，缺预览不新增 HTTP 请求。新增广告与轮播需覆盖“仅电脑有预览、手机原图仍在加载”的首屏回归。
- SafeImage统一消费预览，不要求调用者逐个添加高优先级开关；响应式预览使用与原图一致的原生picture分支。布局和裁切仍由当前图片框决定。
- 导航返回可复用当前公开作用域内已实际解码图片的URL作为画面底层，最多128项，仅存内存；私有图片仍按所有者隔离。保留画面不代表新节点ready，不替代当前候选的实际decode，也不持久化图片或新增请求缓存。
- 原生图片像素始终直接可见，预览底层延续到新节点经过绘制机会再撤下；不能靠隐藏原图、整页遮罩、延迟交互或取消错误反馈防闪。
- 接管时检查图片节点的真实完成状态；若错误早于React事件监听，也必须进入原有局部恢复/错误分支，不能继续假装请求仍在进行。
- 恢复源全部失败后，在原图片框提供局部重试；每次仍走有界恢复链。重试控件不得嵌套在商品链接或按钮内、不得逃逸所在弹窗；小于触控尺寸的装饰图不叠加按钮。联网恢复只自动重试当前可见失败项一次，不重放业务操作。

## 数据、缓存与实时更新

- 普通只读配置沿用根 QueryClient 有界缓存和真实 dataUpdatedAt；同作用域 A→B→A 在新鲜期内不重复首载，过期时保留内容后台读取。禁止离开即清除或每次挂载强制回到 pending。敏感任务凭据、数字交付秘密、支付确认结果保持原隔离与实时校验；`gcTime: 0` 必须在属性前写明 `@ephemeral-sensitive: 原因`，由交互门禁检查，不扩大持久化白名单。
- 根QueryClient是唯一缓存入口。键包含店铺、市场/币种、语言、实际条件；私有数据包含客户身份。
- 同作用域同条件公共数据可直接显示；过期数据后台刷新。目标条件无缓存才局部占位，不能把其他条件结果当成功。空数组与零条是有效结果。
- 搜索的首次分页偏移遵守URL，新关键词或条件重置页码；是否能追加由真实分页状态决定。订单正文不等待可选的最近订单摘要；追加失败在列表尾部恢复。
- 图片工坊组合读取部分失败时只写入成功字段，保留旧的有效数据；全部必需读取成功才推进组合缓存时间。未知余额不能表示为零，旧余额展示不能代替当前付费操作校验。独立2FA连接超过十秒提供局部重试，仍验证原有消息来源及客户归属。
- 同商品价格/库存刷新保留仍有效的规格、数量与信息标签；商品身份或显式URL初始条件变化才重新初始化。规格被移除时安全回退，不把旧规格的数量带到新规格。
- 路由代码预载和公共读取复用现有机制；取消导航只取消自己的等待，不建立额外网络流程。
- refreshStorefrontQueries只刷新当前作用域active reads；普通refetch/fetchNextPage使用cancelRefetch:false去重，signal传到API。客户点击超时重试时，先取消精确查询键的挂起读取，再读取失败的当前页；保留已有结果，旧响应不能覆盖新选择。局部条件变化重新开始读取计时，不重置目标导航的计时。
- 公共会话缓存仅用现有白名单和时限；不新增品牌、客户、购物车或敏感金额持久化。保留原dataUpdatedAt，不伪造更新时间。
- 会话恢复仅补充根 QueryClient 中缺失的公开读取；本地较新的时间戳不是内容版本，不能覆盖已显示的服务端正文或本次已完成的读取。空数组与 null 也必须保留，不能在接管后插回上次访问的图片。恢复入口只接收公开查询，不恢复写操作。
- publicRefreshScheduler是唯一回查调度：SSE断线且联网可见时按既有60秒策略执行；隐藏窗口不轮询。手动刷新与重连复用现有查询。
- 发布失效取消旧代读取；旧响应不得填充当前缓存。店铺/币种/语言/客户变化不复用不兼容数据。
- 钱包、报价、订单确认仍需原业务验证。公共刷新不放宽支付token、身份和权限约束。

## 布局、导航与可访问性

- 正文流中的模块从首帧计算真实几何，禁止用 `content-visibility: auto` 与固定估算高度推迟布局；这会在刷新或滚动恢复时把估算空间替换成真实空间。继续使用已有图片懒加载与查询缓存，不以隐藏正文防闪。新增 CSS 纳入交互门禁。
- SSR与首次客户端共享响应式结构，不挂载两套页面查询。页头、横幅、卡片、图片预留正确空间；长品牌和换行导航允许自然增高。
- SSR公开导航提供真实href与当前语言；未连接的搜索/私有控件局部保留占位。不能以画面存在宣称全部JS操作可用，更不能缓存重放购买点击。
- PageBackButton、goBack/returnToRoute保留现有历史规则。标题/内容/回调身份取Router发布match；不只看最新URL，也不永久绑定旧resolvedLocation。
- 读刷新保留滚动和草稿；新筛选按业务规则重置分页。不能用查询结果覆盖用户正在编辑的输入。
- 跨页面真实提交后把键盘阅读顺序交给可见标题或正文，并保留滚动位置；初次接管、同页筛选/规格、浏览器历史恢复、弹窗和用户已经主动移焦的情况不抢焦点。
- 价格排序同时表达当前方向与下一次操作；筛选价格错误关联到具体输入，复用原提示和按钮位置。
- 图片复用SafeImage和现有响应式候选。商品图沿用contain；明确营销artwork可cover；保留商家原图和裁切选择。
- 状态提供适当role、名称与busy；触控目标至少44px。提示不遮挡关键操作，重试键盘可达。
- OverlayHost/Overlay统一portal、焦点、层级和引用计数滚动锁；归属含店铺/市场/币种/语言/客户/路由。
- 手机底栏保持原生fixed；键盘确实遮挡才使用trackFixedBottomViewport正向补偿。失焦/关闭键盘恢复，不用瞬时viewport差制造上跳。

## 操作和错误

- 回执确认后的正常读回仍是处理中，不代表读取失败。已展示列表保持位置，原按钮继续按业务 busy 限制重复操作，不临时插入异常核对面板；只有真实失败、超时、结果不明或主动恢复才显示原恢复界面。购物车单项勾选、分组和全选覆盖这段中间状态，并验证失败恢复与结算限制仍然有效。

- 搜索保留IME保护、防抖与请求隔离，迟到建议不能覆盖当前关键词。
- 写操作在所属按钮处反馈并防重复。读刷新不能重放下单、领券、支付或邮件。
- 区分未开始、进行中、成功、失败、写入成功但显示更新失败；空数据、网络错误和店铺未开放不能混用。
- 版本变化沿用用户可控提示，敏感操作期间延后。普通数据重试不整页reload。
- 首文档的追加媒体准备必须使用底层读取最终校验通过的版本；不能用读取前的旧版本否定缓存层已完成的合法换代。交接后再次发布、撤权、停用或切币种仍须拒绝，不能通过删除版本或权限守卫消除 503。
- 发布就绪不能只凭 API /health。前端指针切换前复用现有匿名首文档和缓存准备所有配置店铺；准备预算与正式公开验收分开，预热不能替代公开版本、时限和实际交互验收。
- 路由模块加载失败不得自动刷新正在使用的文档；沿用现有错误边界和显式恢复。固定 Router 的自动刷新 guard 由 document-loading 接管，升级工具链必须通过实际 lazyRouteComponent canary 和叶模块/外层拆分模块真实失败浏览器回归，不能只模拟等待。
- 恢复只重试受影响当前读取；启动/渲染资源错误可以重载，不自动重放未确认交易。
- 不新增alert/confirm/prompt；沿用现有业务通知与确认组件。

## 本次实施与验收

本次范围：Router目标正文等待、Boundary接管和必要内容就绪的区分、中央反馈、区域重试、列表尾部等待、启动重复解析与预加载工作，以及加载模块的依赖拆分。品牌等待复用现有SafeImage；保留原有图片候选和失败回退。首页、分类和其他页面的最终布局、内容、图片及交易权限规则不变。搜索和订单只调整读取反馈归属，不改变业务操作。

至少验证以下场景，不能只看最终截图、HTTP成功或线上SHA：

1. 无缓存首进、缓存刷新、慢入口：逐帧核对内容没有先出现再消失，图片不反复透明，壳层不跳位。
2. warm A→B→A、冷路由、同页参数、快速连续点、后退/前进：标题/选中项/数据/回调一致，内容和滚动正常恢复。
3. 原生图片已complete但decode未完成、候选变化、失败、近屏加载：几何、裁切、可见像素、ready与回调都真实。
4. 局部长期等待、空结果、超时、离线、模块失败、迟到恢复：导航仍可用，错误可恢复。
5. 390px和桌面实际组件；1024/1180/1440宽度长导航；中英文、现有主题、减少动态效果；无新增控制台异常。
6. 定向测试、check:interaction、受影响统一性检查和构建。静态门禁不能代替真实浏览器验收。

持续测量首屏内容出现时间、布局位移和输入响应。慢网与冷缓存不承诺任何条件下瞬间全图；报告实际环境、未覆盖项与限制。代码完成、本地验证、发布、线上验收分别记录。

首屏资源门禁同时检查入口、CSS与实际路由静态依赖闭包，不把未压缩文件字节当作线上传输量。标准CWV保留文档语义；SPA导航和图片呈现另记匿名指标，服从既有退出统计选项，不包含URL、商品/客户ID或图片地址。图片观测仅记录实际进入可视区的等待，最多32个框、每轮30秒；未观测不记为零或达标。

NAV_RENDER与NAV_READY只描述已提交目标；NAV_ERROR记录当前目标的真实失败或断网，不把十秒慢读、可选模块错误或已取消导航归为目标失败。中国大陆和马来西亚、手机和电脑的实测分别记录，不能用本地限速或其他候选的报告代替。
